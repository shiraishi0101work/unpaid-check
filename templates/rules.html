{# ===== 1. 概要・データソース ===== #}
1. 概要・データソース

このシステムは MFクラウド請求書のステータス を軸に未入金を判定します。

MFクラウド請求書（必須）
  • 全請求書の入金ステータスを取得
  • 支払期限・請求日・請求金額・取引先名
  • DL済み・メール送付・郵送の送付状況
  • 請求金額が 0円の請求書は除外（テスト用）
システム内データ（補助）
  • 担当者・メモ（社内用メタデータ）
  • 手動着金日・着金金額（手入力）
  • 取引先名→担当者の自動割り当てマップ
{# ===== 2. 分類ルール ===== #}
2. 分類ルール（タブ対応表）
{# 入金確認済み #} {# 一時保管 #} {# 未収 #} {# 請求済み確認 #} {# 下書き（期限超過） #} {# 期日前 #}
分類名（タブ） 判定条件 MFステータス 支払期限 その他条件
入金確認済み（MF） MF請求書ステータスが「入金済み」 入金済み — —
入金確認済み（手動） MF未払いだが 手動着金日が入力済み 未設定 / 未入金 — 手動着金日あり
一時保管 期限超過 かつ 社内メモが入力済み（毎月要確認） 未設定 / 未入金 超過 メモあり
未収 MFで明示的に「未入金」 かつ 期限超過 未入金 超過 メモなし
請求済みか確認 ステータス「未設定」で送付済み かつ 期限超過 未設定 超過 送付済み
下書き（超過） ステータス「未設定」で未送付（下書き状態） かつ 期限超過 未設定 超過 未送付
期日前 MF未払い かつ 支払期限が今日以降（または未設定） 未設定 / 未入金 期日前 / 未設定 手動着金日なし
一時保管の優先度が最高です。 メモが入力されている超過請求書は、他のタブ（未収・請求済み確認・下書き）には表示されません。
{# ===== 3. 未収再確認ルール ===== #}
3. 未収再確認ルール

「まとめて再確認（MF会計）」ボタンを押したときの動作ルールです。未収再確認タブにのみ反映されます。

項目 内容
取得元 MFクラウド会計の仕訳データ（仕訳済み・未仕訳両方）
取得期間 今日から2カ月前の1日〜今日
照合方法 未収請求書の取引先に登録された振込名義と、仕訳の備考欄を照合（カタカナ表記で部分一致）
表示条件 振込名義と備考が一致した仕訳のみ「未収再確認」タブに表示
注意 振込名義が顧客リストに未登録の場合は検出されない
このボタンは 会計未仕分けタブには影響しません。会計未仕分けは「未仕分けチェック（MF会計）」ボタンで独立して取得します。
{# ===== 4. 会計未仕分けルール ===== #}
4. 会計未仕分けルール

「未仕分けチェック（MF会計）」ボタンを押したときの動作ルールです。会計未仕分けタブにのみ反映されます。

項目 内容
取得元 MFクラウド会計の未仕分けデータ（is_realized=false）のみ
取得期間 今日から2カ月前の1日〜今日
表示条件 MFクラウド会計でまだ仕訳が完了していない取引すべて
重複除外 一度取得した取引IDは2回目以降のチェックで重複追加されない
各操作ボタンの動作
編集 振込名義を入力して未収請求書と紐づける。紐づけると未収から消える。
顧客登録 振込名義を顧客リストに登録。次回から「まとめて再確認」で自動検出されるようになる。
削除 一覧から非表示にする（入金でない取引など）。
このボタンは 未収再確認タブには影響しません。
{# ===== 5. MFステータス定義 ===== #}
5. MFクラウド請求書 入金ステータス定義
ステータス値 区分 意味・MF側の状態
入金済み 入金済み MFクラウド請求書上で入金登録が完了している
未入金 未入金 MF側で明示的に「未入金」としてマークされている
未設定 未設定 入金登録が行われていない（デフォルト状態）。下書き・送付後どちらの可能性もある
{# ===== 4. 送付済み判定ルール ===== #}
6. 送付済み判定ルール

ステータスが「未設定」の請求書を 送付済み か 下書き（未送付） か判定するためのルールです。 以下のいずれかを満たせば「送付済み」と判定します。

条件 判定根拠 MFのフィールド
① PDFダウンロード済み is_downloaded = true
② メール送付済み（「未送信」以外のメール状態） email_status ≠ 未送信
③ 郵送済み（「未郵送」以外の送付状態） posting_status ≠ 未郵送
①〜③のいずれも満たさない場合は「下書き（未送付）」と判定し、 下書き（超過） タブに表示されます。
{# ===== 5. 処理フロー ===== #}
7. 処理フロー
1
MFクラウド請求書から全請求書を取得
全件を取得。請求金額0円・指定日付範囲外は除外。
↓
2
メタデータをマージ
担当者・メモ・手動着金日・着金金額をシステム内DBから各請求書に付与。取引先名マップで担当者を自動セット。
↓
3
入金済み / 未入金 の一次分類
MFステータスが「入金済み」→ 入金確認済み（MF）
未払いで手動着金日あり → 入金確認済み（手動）
未払いで手動着金日なし → 未入金（次ステップで細分類）
↓
4
未入金を期限超過 / 期日前 に分類
支払期限が今日より前 → 期限超過グループ（次ステップでさらに細分類）
支払期限が今日以降または未設定 → 期日前
↓
5
期限超過グループをさらに4分類
一時保管 ← メモが入力されている（最優先）
未収 ← MFステータスが「未入金」
請求済みか確認 ← MFステータスが「未設定」かつ送付済み
下書き（超過） ← MFステータスが「未設定」かつ未送付
↓
6
Excelレポート生成 & 結果保存
outputフォルダにExcelファイルを出力。次回起動時も結果を保持。
{# ===== 6. 除外・非表示ルール ===== #}
8. 除外・非表示ルール
操作 対象タブ 動作 復元方法
「削除」ボタン（下書き） 下書き（超過） 一覧から非表示にする。data/deleted_drafts.json に除外IDを記録。 JSONから対象IDを削除し再実行
「未請求として除外」ボタン 請求済みか確認 一覧から非表示にする。data/deleted_seikyu.json に除外IDを記録。 JSONから対象IDを削除し再実行
請求金額 0円 全タブ 実行時に自動除外（テスト・内部用の無効請求書） —
除外したIDは「今すぐ実行」を行っても復元されません。必要な場合は対応する JSON ファイルを直接編集してください。
