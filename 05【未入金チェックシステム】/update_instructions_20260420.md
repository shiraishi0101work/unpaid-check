## 作業手順

### STEP 1: ファイルをサーバーに転送

`unpaid_check_update_20260420.zip` をサーバーに転送し、展開します。

```bash
cd /opt/unpaid_check
unzip -o unpaid_check_update_20260420.zip
```

> `-o` オプションで既存ファイルを上書き確認なしで置き換えます。

---

### STEP 2: サービスを再起動

```bash
systemctl restart unpaid_check
systemctl status unpaid_check
```

「active (running)」と表示されれば完了です。

---

### STEP 3: 動作確認

ブラウザで `https://【ドメイン】/history` にアクセスし、以下を確認してください：

- 月次履歴の一覧カードにゴミ箱ボタン（削除）が表示される
- 「詳細を見る」から各行に鉛筆ボタン（編集）とゴミ箱ボタン（行削除）が表示される
- 「この確定を削除」ボタンが詳細ページ右上に表示される
