# 未入金チェックシステム — サーバーデプロイ手順書

> **エンジニアの方へ**  
> このシステムはPython（Flask）製のWebアプリケーションです。  
> 以下の手順通りに作業すれば、サーバーへのアップロードから起動まで完了します。  
> コードの内容を理解する必要はありません。手順通りに進めてください。

---

## ■ 完成後の動作イメージ

- `https://【設定したドメイン】/` にアクセスするとログイン画面が表示される
- ログイン後、各会社の請求書未入金データを確認できる
- 管理者アカウントで全社のデータをまとめて閲覧できる

---

## ■ STEP 1: ファイルをサーバーに展開する

`unpaid_check_system.zip` をサーバーに転送し、展開します。

```bash
mkdir -p /opt/unpaid_check
cd /opt/unpaid_check
unzip unpaid_check_system.zip
```

## ■ STEP 7: 本番起動（gunicorn + systemd）

### systemd サービスファイルを作成

```bash
nano /etc/systemd/system/unpaid_check.service
```

以下を貼り付けてください：

```ini
[Unit]
Description=Unpaid Check System
After=network.target

[Service]
User=www-data
WorkingDirectory=/opt/unpaid_check
Environment="PATH=/opt/unpaid_check/venv/bin"
ExecStart=/opt/unpaid_check/venv/bin/gunicorn -w 2 -b 0.0.0.0:5000 app:app
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

### サービスを有効化・起動

```bash
systemctl daemon-reload
systemctl enable unpaid_check
systemctl start unpaid_check
systemctl status unpaid_check
```

「active (running)」と表示されれば正常です。

## ■ STEP 8: nginx + HTTPS の設定

### nginx 設定ファイルを作成

```bash
nano /etc/nginx/sites-available/unpaid_check
```

以下を貼り付けてください（【ドメイン名】を実際のドメインに変更）：

```nginx
server {
    listen 80;
    server_name 【ドメイン名】;

    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

```bash
ln -s /etc/nginx/sites-available/unpaid_check /etc/nginx/sites-enabled/
nginx -t
systemctl reload nginx
```

### HTTPS化（Let's Encrypt）

```bash
apt install -y certbot python3-certbot-nginx
certbot --nginx -d 【ドメイン名】
```

指示に従って進めるとHTTPS化が完了します。

## ■ STEP 9: MFクラウド請求書のOAuth設定を更新する

**これを忘れるとMF連携が機能しません。**

1. MFクラウド請求書の開発者コンソールにログイン  
   → https://invoice.moneyforward.com/developer

2. 対象のOAuthアプリを開く（CLIENT_ID: `239946377590530`）

3. リダイレクトURIを以下に変更する：
   ```
   https://【ドメイン名】/oauth/callback/invoice
   ```

4. 保存する
