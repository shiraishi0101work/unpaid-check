# 未入金チェックシステム — サーバーデプロイ手順書

> **エンジニアの方へ**  
> このシステムはPython（Flask）製のWebアプリケーションです。  
> 以下の手順通りに作業すれば、サーバーにアップロードして動作させることができます。

---

## 1. サーバー要件

| 項目 | 要件 |
|------|------|
| OS | Ubuntu 20.04 / 22.04 推奨（CentOS・Debian も可） |
| Python | **3.11 以上**（3.12推奨） |
| メモリ | 512MB 以上（1GB推奨） |
| ディスク | 2GB 以上 |
| ポート | 80（HTTP）、443（HTTPS）開放 |

---

## 2. ファイルをサーバーにアップロード

ZIPファイル `unpaid_check_system.zip` をサーバーの任意のディレクトリに転送し、展開してください。

```bash
# 例: /opt/unpaid_check に展開する場合
mkdir -p /opt/unpaid_check
cd /opt/unpaid_check
unzip unpaid_check_system.zip
```

---

## 3. Pythonパッケージのインストール

```bash
cd /opt/unpaid_check

# 仮想環境を作成（推奨）
python3 -m venv venv
source venv/bin/activate

# 必要パッケージをインストール
pip install -r requirements.txt
```

---

## 4. 設定ファイルの作成（重要）

`.env.example` をコピーして `.env` を作成し、必要項目を記入します。

```bash
cp .env.example .env
nano .env   # または vi .env
```

### 記入が必要な項目

```
MF_INVOICE_CLIENT_ID=      ← クライアントから受け取るCLIENT_ID
MF_INVOICE_CLIENT_SECRET=  ← クライアントから受け取るCLIENT_SECRET
MF_INVOICE_REDIRECT_URI=https://【実際のドメイン】/oauth/callback/invoice

FLASK_SECRET_KEY=          ← 下記コマンドで生成したランダム文字列を貼り付け
```

**FLASK_SECRET_KEY の生成方法：**
```bash
python3 -c "import secrets; print(secrets.token_hex(32))"
```

### MFクラウド請求書 OAuthアプリの設定

MFクラウド請求書の開発者コンソール（https://invoice.moneyforward.com/developer）にて、  
リダイレクトURIを以下に変更してください：

```
https://【実際のドメイン】/oauth/callback/invoice
```

---

## 7. 本番運用（gunicorn + systemd）

### gunicorn での起動テスト
```bash
gunicorn -w 2 -b 0.0.0.0:5000 app:app
```

### systemd サービスとして登録（自動起動）

`/etc/systemd/system/unpaid_check.service` を作成：

```ini
[Unit]
Description=Unpaid Check System
After=network.target

[Service]
User=www-data
WorkingDirectory=/opt/unpaid_check
Environment="PATH=/opt/unpaid_check/venv/bin"
ExecStart=/opt/unpaid_check/venv/bin/gunicorn -w 2 -b 0.0.0.0:5000 app:app
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload
systemctl enable unpaid_check
systemctl start unpaid_check
systemctl status unpaid_check   # 動作確認
```

---

## 8. nginx リバースプロキシの設定（HTTPSにする場合）

`/etc/nginx/sites-available/unpaid_check` を作成：

```nginx
server {
    listen 80;
    server_name 【ドメイン名】;

    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

```bash
ln -s /etc/nginx/sites-available/unpaid_check /etc/nginx/sites-enabled/
nginx -t
systemctl reload nginx
```

HTTPS化には certbot（Let's Encrypt）の使用を推奨します。

## 9. 初回ログイン

デプロイ完了後、ブラウザで `https://【ドメイン】` にアクセスすると、  
**初回アカウント設定画面**が表示されます。

- 管理者メールアドレスとパスワードを設定してください
- 設定後、ログイン画面が表示され通常利用開始できます

## 10. トラブルシューティング

| 症状 | 確認箇所 |
|------|----------|
| 起動しない | `.env` の記入漏れ、Python バージョン確認 |
| MF連携できない | リダイレクトURIがMF開発者コンソールの設定と一致しているか確認 |
| 500エラー | `journalctl -u unpaid_check -f` でログを確認 |
| ポートが開かない | ファイアウォール設定（`ufw allow 5000`）を確認 |
